# Poverka statusa: git status !
* Dobaviti izmenenia: git add
* Dobaviti toliko odin fail: git add index.js
* Sdelati commit: git commit -m
* Otpraviti na GITHUB: git push
* Esli pervii raz push-ite v novuiu vetku: git push -u origin main
* Zabrati obnavlenia s GITHUB : git pull
* Sozdati novuiu vetcu: git checkout -b feature-branch
* Perecliucitsea na druguiu vetku: git checkout main
* Posmotreti spisoc vetoc : git branch
* Istoria commit-ov:git log --online
